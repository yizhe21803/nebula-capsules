## 帧序列结论
1. 发光边界不是等频正弦波，也不是多条可见海浪线，而是一条持续形变的流体海岸线。
2. 相邻帧形状高度连续，变化缓慢；主要变化来自低频大块隆起，细节只做轻微扰动。
3. 边界上下两端接近直线，中段形变最明显。
4. 主边界后方存在两层模糊色带和多个缓慢漂移的色团，但只有最前方一条亮边。
5. MODEL TRAINING 的细节频率最高；AGENT MIGRATION 最平滑；VISUAL TRAINING 介于两者之间。
6. 百分比位置与流体形变相互独立：拖动只改变海岸线基准位置，内部色团和边缘形变持续播放。
7. 原视频没有断续泡沫线、虚线浪花或多条规则并行波峰。

## 本版实现调整
- 使用二维连续值噪声与四层 FBM 生成非周期边界。
- 使用低频、中频、细节和局部隆起四个尺度叠加。
- 边界振幅在上下两端自动衰减。
- 只保留一条主发光边缘；后方色层均模糊处理。
- 三条胶囊分别使用不同振幅、细节量和流速。
- 保留自动加载、手动拖动、键盘调整和“进度”筛选。
- NC-01～NC-09 的原文件不写入更新包。
